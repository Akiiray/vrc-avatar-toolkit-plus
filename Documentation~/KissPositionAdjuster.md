# Kissギミック位置調整

導入済みのRealKissSystemとJustKissSFXの位置を、アバターの現在の顔形状から推定します。商用アセットは別途入手し、先にアバターへ導入してください。初期対応はRealKissSystem 1.4.0のMA版とJustKissSFX 1.11のMA版（通常／WD Off）です。移動ルートと追従構造を確認できる構成を対象にします。

## 操作

1. Hierarchyにあるアバター、またはその子を選択します。
2. `Tools > VRC Avatar Toolkit Plus > Kissギミック位置調整` を開き、必要なら「Hierarchy の現在選択から設定」を押します。
3. 調整するギミックを選び「自動位置推定」を押します。同種が複数ある場合は対象Transformを確認して明示選択します。
4. Scene Viewで灰色の現在位置と色付きの候補、Contactの範囲、JustKissSFXの音源位置を確認します。位置ハンドルまたはウィンドウの座標欄で微調整できます。
5. 「調整結果を適用」を押します。変更はHierarchy側に記録され、Undoでまとめて戻せます。「プレビュー解除」は配置を変更せずに候補を消します。Undo／Redoや顔・構成の変更後は、必要に応じて再検出・再推定してください。

| JustKissSFXの配置基準 | 動作 |
| --- | --- |
| 鼻先候補（標準） | 口元より上の、正面に向いた突出部を使う。鼻が不明瞭な場合は警告付きで中点の仮候補を表示 |
| 鼻と口の中点 | 鼻候補と口の前方表面の間に配置 |
| 口元候補 | 複数のVisemeが一致した口元を使用 |

## 推定と制限

- Avatar Descriptorで指定したVisemeと、現在のボーン・BlendShapeを反映した顔メッシュを使います。RealKissは口元候補を前向きの面へ投影します。面が見つからないときは警告付きで口元候補を残します。
- 位置のみを変えます。回転、Scale、Radius、Height、既存のParent Constraintオフセットは維持します。CenterOfHeadへ追従する音源は、追従を維持したまま一緒に移動します。
- Prefab AssetとPrefabモードは対象外です。VisemeやHumanoid Headが不足する場合、追従構造を確認できない場合、負・非一様・せん断を含むScaleの場合、解析または適用を停止します。鼻が平坦な場合などは側面から調整してください。
- プレビューはEditor上の位置予測です。ビルド後の位置、VRChat内の発火距離、音の聞こえ方は実際の条件で確認してください。
